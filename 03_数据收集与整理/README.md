## 数据口径

- 原始观察单位：公司—股东大会—议案。
- A股赞成率 = A股赞成票 / (A股赞成票 + A股反对票 + A股弃权票)。
- H股赞成率 = H股赞成票 / (H股赞成票 + H股反对票 + H股弃权票)。
- Gap = |A股赞成率 − H股赞成率|，单位为百分点（pp）。
- SignedGap = A股赞成率 − H股赞成率。
- 对于公告没有披露A/H分类票数的记录，不用整体票数替代，不将缺失值记为0。
- 累积投票、关联股东回避、股份类别特定事项及同一父议案下的子议案均应单独标记。

## 重要限制

1. 211组代码配对是当前候选名录，不是已经完成交易所逐项核验的最终总体。公开市场统计存在日期和口径差异，需进一步核验公司状态、上市日期、证券代码及退市/转换情况。
2. 六家公司只覆盖各自2024年度股东大会（实际召开于2025年5—6月），不代表这些公司全部年度和临时股东大会。
3. 议案投票数字已按决议公告整理，但正式回归前仍需逐项回到公告原文进行二次核验，尤其是特殊表决、回避表决和子议案。
4. 该试验样本是目的性选取，不具有总体代表性。当前结果只能说明初步可行性和研究线索，不能作为因果结论或总体规律。
5. H股股东不等同于境外机构投资者，A股股东也不等同于境内个人投资者。不能仅凭股份类别推断投资者身份、信息优势或偏好。

## 下一步

1. 逐项核验候选名录，补充A股/H股上市日期、行业、上市状态。
2. 以每家公司实际完成A/H双重上市后的日期为起点，按2018—2025年候选期间收集全部年度及临时股东大会。
3. 建立会议覆盖率表，区分“有会议公告”“有分类投票结果”“有可计算A/H Gap”三个层次。
4. 完成议案类别编码手册及异常/特殊事项标记。
5. 在扩大样本后再确定主研究方向：未来AH相对定价结果，或特定议案对应的后续公司行为。
